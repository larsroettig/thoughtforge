Features

Everything you need to plan, without leaving your machine

📋

Smart Task Dashboard

Filters for My Tasks, Overdue, Due Today, Blocked, and more — across all your projects at once.

🗂

Kanban Board

Four views: by urgency, by status, day-by-day, or calendar. Drag tasks between columns to update them.

📁

Project Spaces

Per-project workspaces with notes, meetings, tasks, booked hours, goals, and semantic search.

🤖

AI Chat & Planning

Ask your local LLM to plan your day, triage blockers, or summarize a project. Changes need your approval before they're saved.

📄

Document Processing

Upload meeting transcripts (.txt, .md, .pdf) and extract action items automatically.

🔍

Semantic Search

Vector-indexed notes per space. Search with natural language — powered by a local embedding model.

⏱

Time Tracking

One-click timer on tasks, book hours per project, weekly timesheet grid, and stats with daily activity chart.

🎯

SMART Goals

Track goals with metric, target, current value, difficulty, and due date — linked to project spaces.

🔌

MCP Server

Built-in Model Context Protocol server — connect Claude Desktop or any MCP client to your vault directly.

Built-in MCP Server

ThoughtForge ships a Model Context Protocol server. Enable it in Settings and connect Claude Desktop or any MCP client — create tasks, search notes, and manage goals directly from Claude.

# Add to claude_desktop_config.json
"thoughtforge": {
  "command": "/path/to/vaultmind-mcp",
  "args": ["--stdio"]
}
